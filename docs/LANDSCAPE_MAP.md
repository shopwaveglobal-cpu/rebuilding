# Landscape Map v0.1

현재까지 대화에서 확인된 정보만 사용한 1차 지도입니다. 확정 계획이 아니며, 수치와 사실은 검증 후 갱신합니다.

## 공통 출력 형식

각 영역은 다음 순서로 갱신합니다.

1. Desired State
2. Why
3. Current State
4. Gap
5. Non-Negotiables
6. Metrics
7. Possible States
8. Risks / Contradictions
9. Unknowns
10. MUST / WANT / NOT NOW / NEVER

- Current State: 수면, 운동, 영양, 회복의 기준값 `TBD`

- Metrics 후보: 수면시간, 운동 수행률, 퇴근 후 에너지 `1 ~ 5`
- Non-Negotiables: 수면, Movement, 근력, Zone 2, 회복

## Business

- Desired State: Owner Profit `3S × 6개월`
- Current State: 안정적인 수익 엔진 미구축, 사업·채널 아이디어 존재
- Gap: 지불 의사가 있는 고객 문제와 반복 가능한 Offer 부족
- Metrics 후보: 고객 대화, 문제 검증, 제안 수, 결제 수, Owner Profit
- Hypothesis: 비개발 실무자를 위한 AI 업무자동화 설계·구축

## Brand

- Desired State: 1IM / Time Creator가 장기 브랜드 자산으로 작동
- Current State: AI·자동화·시간 회복을 직접 실험하고 공유하려는 방향
- Gap: Audience, Persona, Promise, Content Pillar의 검증 필요
- Positioning: 실제 직장생활과 삶에서 AI·시스템을 실험하고 시간을 되찾는 비개발자

## Learning

- Strategic Learning: 현재 Mission 수행에 필요한 AI, 자동화, 브랜딩, 사업, 판매, 금융
- Life Expansion Learning: 역사, 철학, 문학, 과학, 인물, 여행
- Rule: 막연한 AI 공부를 Active Task로 만들지 않음
- Method: Build → Blocked → Learn → Apply

- Trigger 후보: 야근, 사업 집중시간, 퇴근 에너지, 건강, 소득 안정성

- Unknowns: 정상 퇴근 비율, 주당 사업 가능 시간, 가족 리스크 허용 수준 `TBD`
