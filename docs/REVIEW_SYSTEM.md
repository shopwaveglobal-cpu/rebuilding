# Review System

## 주기별 권한

| 주기 | 허용되는 결정 |
|---|---|
| Daily | 실행 방법 변경 |
| Weekly | Task 우선순위 변경 |
| Monthly | 프로젝트 방식·상태 변경 |
| Quarterly | Mission 변경 |
| 6개월 | 2-Year 전략 변경 |

## Daily

오늘의 상태, 운동 최소버전, 유일한 핵심 Outcome, 가족·회복 약속을 확인합니다. 새로운 Active Project는 만들지 않습니다.

## Weekly CEO Review

다음 항목을 검토하고 가장 큰 Bottleneck 하나와 다음 주 Outcome 하나를 정합니다.

- Energy: 운동률, 수면, 퇴근 에너지
- Business: Deep Work, 고객 문제, 제안, 매출
- Brand: 발행, 저장, 공유, 반응
- Family: 약속 이행
- Work: 야근시간, 정상 퇴근 비율

## Monthly Review

현재 State, Monthly Contract, Input·Output·System KPI, STOP LIST를 검토합니다. 결과는 `PASS`, `HOLD`, `PIVOT`, `KILL`, `EXPAND` 중 하나입니다.

## Quarterly Review

North Star와 90-Day Mission의 정합성을 검토합니다. 경로는 바꿀 수 있지만 North Star와 Freedom 정의는 충분한 근거 없이 바꾸지 않습니다.
