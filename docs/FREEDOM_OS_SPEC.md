# Freedom OS — System Specification v0.1

## 1. 정의

Freedom OS는 시간 통제권을 핵심 자산으로 삼는 개인 운영체계입니다. 목표는 회사 급여에 대한 생계 의존도를 줄이고, 본인 사업과 시스템으로 가족·건강·경험·창작에 사용할 시간을 확보하는 것입니다.

## 2. 핵심 구조

```text
Today's Action
```

## 3. 성장 엔진

- `ENERGY`: 퇴근 후에도 삶과 사업을 실행할 수 있는 신체·정신 에너지
- `BUSINESS`: 회사 밖에서 반복적으로 돈을 만드는 시스템
- `BRAND`: 1IM / Time Creator와 Audience
- `LEARNING`: 전략 학습과 삶 확장 학습
- `LEVERAGE`: AI, 자동화, 사람, 자본으로 직접 노동을 줄이는 능력
- `LIFE`: 성장 KPI가 아니라 사업을 하는 이유이자 보호해야 할 영역

각 엔진의 상세 현재 상태는 [Landscape Map](LANDSCAPE_MAP.md)을 기준으로 합니다.

## 4. Business Flywheel

```text
My Problem → AI/System Solution → Real Use → Content → Audience
→ Brand → Community → Customer Pain → Offer → Revenue
→ Productization → Automation → More Time
```

## 5. 사업 가설

현재 사업모델은 확정하지 않습니다.

- Cash Engine 후보: AI 업무자동화 구축, Productized Service, Consulting, 교육, Workflow 개선
- Scale Engine 후보: Template, Digital Product, Course, Community, Membership, Agent, Software, SaaS
- 원칙: 실제 고객 문제와 지불의사를 확인하기 전에는 SaaS를 만들지 않습니다.

## 6. 운영 원칙

- Destination Fixed, Route Adaptive
- Active Mission은 최대 2개를 기본값으로 둡니다.
- 새 아이디어는 기본적으로 Inbox 또는 Parking Lot으로 보냅니다.
- Build → Blocked → Learn → Apply 순서로 학습합니다.
- 같은 작업을 세 번 반복하면 AI, 자동화, SOP, 템플릿, 외주를 검토합니다.
- Freedom OS 구축 자체가 생산적 미루기가 되지 않도록 시장·고객·콘텐츠·판매를 우선합니다.
