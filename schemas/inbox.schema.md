# Inbox Schema

| 필드 | 설명 |
|---|---|
| `captured_at` | 수집 시각 |
| `raw_input` | 원문 |
| `category` | Business, Energy, Brand, Learning, Life, Risk, Other |
| `mission_link` | 현재 Mission과의 연결 또는 `None` |
| `recommended_state` | Next Action, Parking Lot, Trigger, Archive |
| `decision_needed` | 사용자 판단 필요 여부 |
| `next_review` | 재검토일 또는 `TBD` |
