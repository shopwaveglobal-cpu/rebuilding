# KPI Schema

| 필드 | 설명 |
|---|---|
| `name` | KPI 이름 |
| `area` | 연결된 영역 |
| `type` | Input, Output, System, Guardrail |
| `definition` | 계산·기록 방법 |
| `unit` | 시간, 횟수, 원, 비율 등 |
| `target` | 목표값 또는 `TBD` |
| `source` | Notion, Calendar, 수동 기록 등 |
| `cadence` | Daily, Weekly, Monthly |
| `decision_use` | 이 값으로 어떤 결정을 하는지 |
