# Monthly Contract Schema

| 필드 | 설명 |
|---|---|
| `month` | 대상 월 |
| `current_state` | 시작 시점의 상태 |
| `growth_missions` | 1 ~ 3개의 Mission |
| `input_kpis` | 행동·투입 지표 |
| `output_kpis` | 결과 지표 |
| `system_kpis` | 시스템·자동화 지표 |
| `promotion_condition` | 승급 조건 |
| `maintenance_condition` | 유지 조건 |
| `stop_list` | 이번 달 하지 않을 것 |
| `review_result` | PASS, HOLD, PIVOT, KILL, EXPAND |
